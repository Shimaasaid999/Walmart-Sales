# 🛍️ Walmart Sales Analysis

A Power BI dashboard project analyzing weekly Walmart store sales in relation to economic and seasonal factors.

## 📌 Overview

This project explores Walmart's weekly sales data across multiple stores, examining how factors like holidays, temperature, fuel prices, CPI (Consumer Price Index), and unemployment relate to sales performance. The analysis is delivered as an interactive **Power BI (.pbix)** dashboard.

## 📊 Dataset

The dataset (`Walmart_Sales.csv.xlsx`) contains weekly sales records with the following fields:

| Column | Description |
|---|---|
| `Store` | Store identifier |
| `Date` | Week of sales |
| `Weekly_Sales` | Total sales for the store that week |
| `Holiday_Flag` | Whether the week includes a holiday (1) or not (0) |
| `Temperature` | Average temperature for the week |
| `Fuel_Price` | Fuel price in the region |
| `CPI` | Consumer Price Index |
| `Unemployment` | Unemployment rate |

## 🗂️ What's Included

- **Interactive dashboard** built in Power BI, exploring sales trends across stores, the impact of holidays on weekly sales, and correlations with macroeconomic indicators (temperature, fuel price, CPI, unemployment).
- **Raw dataset** used to build the report.

## 🛠️ Tech Stack

- **Power BI** — dashboard and data visualization
- **Excel** — source data

## 🚀 Getting Started

### Prerequisites
- [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free)

### Usage
1. Clone or download this repository.
2. Open `Walmart Sales.pbix` in Power BI Desktop to explore the interactive dashboard.
3. The underlying data is available in `Walmart_Sales.csv.xlsx` if you'd like to explore it separately or refresh the report with updated data.
